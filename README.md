Simple Item ManagerA lightweight Python command-line application that allows users to manage a dynamic list of items. Users can add, view, and remove items through a simple interactive menu.FeaturesAdd Items: Input item names to store them in a list.Display Items: View all currently stored items.Delete Items: Remove specific items by name with built-in validation to check if the list is empty or if the item exists.Persistent Loop: The application runs continuously until the process is manually terminated.How to UsePrerequisites: Ensure you have Python installed (the project was developed using Python 3.14 as seen in image_b1fd39.png).Run the script:Bashpython test.py
Navigate the Menu:Enter 1 to add a new item.Enter 2 to see your list.Enter 3 to delete an item.Code StructureThe project is contained within a single script (test.py) and utilizes several key functions:FunctionDescriptionMain_menu()Displays the available user options.Add_Item()Appends a user-defined string to the items list.Display_Items()Prints the list and alerts the user if it is empty.Delete_Items()Handles the removal of items with safety checks.
